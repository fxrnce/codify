# Codify admin maintenance notes

Follow `AGENTS.md` and the Expo SDK 54 documentation before changing the app.
The active administrator experience is the role-gated mobile UI under `app/admin/`
and `app/(tabs)/admin.tsx`. The committed `admin/` web files are reference only.

Backend routes live in `backend/src/routes/admin.routes.ts`. Authorization must be
checked against `User.role` on every request. Keep optimistic locking through the
client-provided `updatedAt`, preserve audit logs, prevent equivalent UPC/EAN
duplicates, and never rerun catalog seed data during normal server startup.

Before committing, run the root lint, root typecheck, Expo dependency check,
Prisma validation, backend typecheck/build, backend admin tests, and
`git diff --check`. Review the complete working tree and create a commit only when
the user explicitly requests it.
